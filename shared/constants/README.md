# Shared Constants

Cross-cutting values that must match on both sides (e.g., the `ReportStatus` enum values, the
`ImpactLevel`/`ComplexityLevel` enum values for AI Growth Opportunities™, pagination defaults).
Documented here as the source of truth; kept in sync manually with
`backend/app/models/*.py` enums and `frontend/src/types/*.ts` unions until codegen exists.
