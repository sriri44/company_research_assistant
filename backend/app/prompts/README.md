# Prompts

Prompt templates are content, not code — reviewed like copy, versioned like everything else.

Naming convention: `<purpose>.prompt.md` (e.g. `company_summary.prompt.md`,
`competitor_analysis.prompt.md`, `opportunity_scoring.prompt.md`). Loaded by
`app.ai` clients via `AIService.generate(prompt_name=...)`. No prompt authoring happens in Phase 1 —
see [docs/ROADMAP.md](../../../docs/ROADMAP.md) Phase 3 and Phase 5.
